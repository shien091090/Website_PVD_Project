# PVD計畫網站 素材與文案清單

需要使用者提供的東西。標「必要」的沒有就不能正式上線；標「可選」的沒給會用預設。

## 一、每款遊戲（4 款各一份）

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 遊戲代號 | 必要 | 英文小寫加連字號，用在網址，例如 `slime-tetris`。上線後不要再改 |
| 遊戲名稱 | 必要 | 中文，建議 8 字以內（清單卡片寬度有限） |
| 遊戲圖示 | 必要 | **正方形 PNG，512×512**，背景不透明。網站會自動裁成圓角並加粗框，所以重要內容放在中間約 80% 範圍內（四角會被裁掉）。網站顯示尺寸 30–150 px，512 可涵蓋高解析螢幕 |
| 遊戲介紹 | 必要 | 1–2 句，建議 30–60 字（手機抽屜與電腦詳情都要放得下） |
| 遊玩時長 | 必要 | 例如「5–10 分鐘」 |
| 支援裝置 | 必要 | 「只支援電腦」或「電腦與手機都支援」。目前 4 款都是只支援電腦 |
| 遊戲主色 | 必要 | 一個色碼，用在選中時的卡片底色。建議從影片輔助色挑：#f29cac 粉、#aaefd5 薄荷、#4776c3 藍、#e0c64f 金；主色上的字要深色還是白色也一併說明 |
| 遊戲檔案 | 必要 | 遊戲資料夾（`index.html` 為入口），所有資源用相對路徑。單一檔案不超過 25MB |
| 遊戲畫面比例 | 必要 | 網站以 16:9 顯示；若不是 16:9 請告知（會加黑/白邊） |
| 操作方式說明 | 可選 | 例如「方向鍵移動、空白鍵跳」。目前畫面沒有放這段，若要放需另外討論位置 |
| 分享預覽圖 | 可選 | 1200×630 PNG/JPG，單款遊戲被分享時的預覽圖。沒給就用全站預覽圖 |

**遊戲本身需要配合修改**（使用者另開 session 處理遊戲時一起做）：照《遊戲接入規範》（`docs/遊戲接入規範.md`）。上線前必做的只有「移除一局結束時下載試玩紀錄的機制」；鍵名格式與暫停/繼續可之後再改。

## 二、全站

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 網站標題 | 必要 | 瀏覽器分頁與分享時顯示，例如「PVD計畫｜梅拉利卡工作室」 |
| 網站簡介 | 必要 | 分享到社群時的說明文字，約 50–80 字 |
| 全站分享預覽圖 | 必要 | 1200×630 PNG/JPG（可用影片截圖加標題） |
| 網站小圖示 | 必要 | 正方形 512×512 PNG（或 SVG）。網站會產生 32×32、180×180（iPhone 主畫面）等尺寸 |
| 首頁宣傳影片 | 可之後換 | 亮色、暗色各一支橫版（已有）；直版可選。MP4（H.264），單支不超過 25MB。換新版前先用現有的 |
| 網址 | 可選 | 先用 Cloudflare 免費網址；買了網域再告知 |

## 三、首頁介紹區文案（目前是示意文字）

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 大標 | 必要 | 一句話，建議 20 字內。目前示意：「一起決定下一款遊戲要長什麼樣子」 |
| 開場段落 | 必要 | 約 60–120 字 |
| Play / Vote / Develop 三段說明 | 必要 | 每段 1–2 句，約 30–50 字 |
| 結語 | 可選 | 目前示意：「這款遊戲，獻給一同參與開發的你們。」 |

## 四、開發頁

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 工作室名稱 | 必要 | 中文名 + 英文名（Meraklika） |
| 工作室 LOGO | 必要 | **SVG 優先**，或透明背景 PNG 512×512。顯示在約 64–96 px 的方框內 |
| 工作室簡介 | 必要 | 約 60–100 字 |
| Threads / Facebook / Discord 連結 | 必要 | 完整網址；要加其他平台也一起列 |
| 開發狀況、近期目標 | 上線時可先空 | 之後由使用者自己改 repo 裡的文字檔更新（格式會附說明） |
| 最後更新日期 | 跟著內容 | 每次更新內容時一起改 |

## 五、投票

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 第一輪起訖時間 | 必要 | 台灣時間，例如 2026/11/10 20:00 – 2026/11/30 20:00（2–4 週）。可之後在後台設定 |
| 投票題目 | 已定 | 「哪一款遊戲你希望開發者繼續做完?」 |

## 六、留言頭像

| 項目 | 必要性 | 規格 / 說明 |
|---|---|---|
| 8 個頭像 | 可選 | 正方形 PNG 256×256 或 SVG，會被裁成圓形，重要內容放中間。沒給就用目前程式畫的 8 個色塊表情 |

## 七、帳號與設定（使用者要自己申請）

| 項目 | 說明 |
|---|---|
| Cloudflare 帳號 | 用來放網站、資料庫、後台登入。申請後把實作者需要的權限給出來（會另外說明步驟） |
| PostHog 帳號 | 免費方案。建立專案後提供專案金鑰 |
| GitHub repo 權限 | 已提供：https://github.com/shien091090/Website_PVD_Project.git |
| 後台登入 email | 只有這個 email 能進後台 |

## 八、建議另外準備
- **隱私說明**：網站會用 cookie 記錄訪客編號與主題分組、並用 PostHog 收集瀏覽數據。建議頁尾放一段簡短說明（可由 Claude 起草，使用者確認）。
- **社群貼文連結清單**：每個平台、每篇貼文各一條帶追蹤參數的連結（網站會附產生方式），發文前準備好。
