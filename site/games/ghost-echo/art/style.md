## 形狀語言

圓角方塊角色、扁平無漸層的場景塊; 狀態靠「亮色 vs 暗色 + 實心 vs 虛線」切換; 「實心擋路」只有地面材質一種長相; 按鍵提示一律同一種淺色鍵帽(外框色 = 它屬於哪個系統); 量條一律「深色常駐軌道 + 預先染暗紅的警告段 + 分界刻度」; 遊戲世界裡的文字帶深色描邊; **教學是紙白圓角泡泡 + 尾巴, 深色粗外框, 裡面深色字**。

## 理念落實

- P0: 玩家 = 實心奶白 + 深外框; 幽靈 = 同剪影半透明淡藍 + 虛線外框; 危險只用紅; 可互動物件各有專屬色 + 專屬記號。教學泡泡用明度反轉(淺底深字)和所有遊戲物件分開, 一眼知道「這是說明, 不是場上的東西」。
- P1: 最顯眼的仍是「現在可以鉤」、瞄準箭頭、壓板量條與節奏燈; 教學泡泡只有一顆、一行字, 尾巴指向錨點, 不放大不常駐閃爍; 開場橫幅半透明、1.5 秒自動消失、放在出生點(左下)的對角上方, 不擋玩家第一眼要看的角色。
- P2: 幽靈頭頂實線、實心 / 單向平台、壓板量條與燈座常駐、HUD 計時器照舊。教學的「已按過的鍵」畫成亮綠底 + 小勾, 玩家看得到教學在等哪個鍵。
- P3: 教學泡泡的鍵帽與遊戲內同一種(Z 加鉤爪色框、C 加綠燈色框、← → 空白鍵 R 用無框原樣); 「綠 = 對了」只在節奏燈 ok 與教學完成; 開始畫面、橫幅、解鎖頁的小圖全部呼叫遊戲內畫法並給規則上成立的 state(解鎖頁鉤爪: 角色已射出在空中 → 幽靈不畫可鉤框; 開始畫面見「物件表」的取捨)。
- P4: 教學 vs 遊戲物件 = 明度反轉 + 外形(帶尾巴的泡泡)兩條通道; 標示框 vs 門開著的虛線框 = 顏色(紙白 vs 洋紅)+ 動態(脈動、虛線繞行 vs 靜止); 已按過的鍵 = 底色變綠 + 角落勾勾。
- P7: 解鎖頁拿掉操作說明與示意圖鍵帽(由教學承擔); 橫幅拿掉提示句; 開始畫面只放遊戲名、小圖、開始提示、靜音, 不加副標。教學泡泡只有 head 階段帶規格指定的向下小箭頭, 其他階段不加裝飾圖示。
- P9: 泡泡深色粗外框, 壓在三代幽靈、壓板斜紋、亮色平台上照樣分得出邊; 標示框有深色襯底。
- P13: 同時只有一顆泡泡(規格保證); 完成特效 0.8 秒內自己縮小淡出到完全消失, 下一顆才出來。
- P15: 完成特效是場上唯一「大勾 + 8 顆星點」的演出, 範圍只比泡泡大一圈; 不和吹哨大環、過關面板同形。
- P17: 計時器與壓板量條照舊(圖形給「離警告段多遠」); polish-6 起警告段與刻度依該關升起時間換算, 第 6 關 1.7 秒時暗紅段仍準確代表「最後 0.3 秒」。
- P2: 第 6 關沒有坑, 背景就不畫坑底警示——規則上不存在的危險不出現在畫面上。
- P18: 教學完成後不再出現, 但它教的按鍵仍常駐在 HUD(Z 鉤爪、C 吹哨、R 重來、M)與物件旁(Z、C 鍵帽)。
- P19: 泡泡尾巴直接指到錨點(角色頭頂、幽靈頭頂、開關、節奏燈); 講的是場上某物件時, 再用標示框直接圈住那個物件本身。
- P21: 本輪沒有說明頁示意圖; 開始畫面小圖用「地上淡化的你 → 虛線跳躍弧 → 站在 1 號幽靈頭上的你」, 讓「踩著上一代往上」與「兩個人一起玩」分得開(見下)。

### drawTutorial 細節

state: `stage`(13 種 id)、`text`(一行字)、`keys`(陣列: 'left' / 'right' / 'jump' / 'Z' / 'C' / 'R')、`pressed`(與 keys 等長的布林陣列)、`ax`, `ay`(錨點)、`place`('above' / 'below')、`pop`(0~1)、`done`(0~1)、`mark`({x, y, w, h} 或 null)。

- **版面**: 泡泡高 54, 左右內距 16; 內容由左到右「文字(24px 粗體深色)→(head 階段)向下小箭頭 → 鍵帽(高 32, 間距 8)」。最窄 96。泡泡水平置中於 ax, 夾在畫布內(邊距 12)。
- **位置**: above = 泡泡底緣在 ay − 18, 尾巴尖在 ay − 4; below = 泡泡頂緣在 ay + 18, 尾巴尖在 ay + 4。泡泡被夾到畫布邊時尾巴仍指向 (ax, ay)。垂直方向不自動翻轉, 照 place 畫(遊戲端已依「超出 y 110 改下方」決定)。
- **鍵帽**: keys 對應 'left' → ←、'right' → →、**'jump' → ↑**(polish-6 改, 與 ← → 同尺寸)、'Z' / 'C' / 'R' 原字。← / → / ↑ / R = 遊戲內同一種淺色鍵帽 + 下方一條深色厚度; Z 外加鉤爪色框、C 外加綠燈色框(和幽靈旁 Z、壓板旁 C 一樣)。move 階段三顆 ← → ↑ 等寬並排。
- **已按過(pressed[i] = true)**: 鍵帽底換淡綠、邊換深綠、右上角綠底白勾小圓; 由 false 變 true 的那一刻彈一下(0.26 秒, 上浮 7px + 放大 20%; 美術內部計時, RD 不必傳)。
- **出現(pop 0 → 1)**: 從尾巴尖端長出來, 彈性縮放(略過頭再回到 1), 不透明度在 pop 0~0.33 從 0 到 1。
- **完成(done 0 → 1, 0.8 秒)**:
  - 0~0.45: 泡泡底疊綠光一閃(最亮在 0.22), 外框換綠; 之後保留淡綠底
  - 0~0.25: 泡泡中央彈出大勾勾(綠圓 r 25 + 白勾, 深外框)
  - 鍵帽依序彈一下: 第 i 顆在 done = 0.1·i ~ 0.1·i + 0.2(move 階段三顆依序)
  - 0.08~1: 8 顆小星點(綠 / 白交錯)從泡泡中心往外散開(橫向約 ±175、縱向約 ±104)並淡出
  - 0.55~1: 泡泡與大勾勾往中心縮到 45%、淡出; done = 1 時什麼都不畫
- **標示框(mark 非 null)**: 物件外擴 6~10px 的圓角框, 紙白虛線(3.5 寬, 段 12 / 8)+ 深色襯底, 約 0.9 秒一次脈動(外擴與亮度), 虛線緩慢繞行。跟著泡泡的出現 / 淡出一起出現 / 消失。畫在泡泡之下。
- 脈動與鍵帽彈跳用美術內部時鐘(瞄準暫停時標示框仍會脈動, 可接受: 只有 hookFire 階段在瞄準中顯示, 且它沒有標示框)。
