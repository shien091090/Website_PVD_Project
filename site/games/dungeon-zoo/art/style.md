## 3. 形狀語言

圓潤扁平 + 深色描邊。**尖角 / 鋸齒只給危險**;其他記號一律圓頭(樓梯與出口的箭頭、石碑圓頂、寶箱圓蓋都是圓的)。**虛線框 + 由內長大的填色 = 「快生效了」**(冰柱射線、爆炸桶、**爆竹、表演場炸藥桶**同一套)。**金色實線框 = 游標**,**金色虛線 = 你打得到的場景物**。**白色外擴環 = 表演**。**金色小光點 / 星芒 = 這裡有好東西**(沒拿過的石碑、沒開的鑰匙寶箱、拿到卡的光芒;拿過 / 開過就熄;**第 12 輪的金幣寶箱改用「箱縫一條金線」, 一樣開過就熄**)。**按鍵一律是鍵帽**(含新的 `[空白]` 寬鍵帽)。教學泡泡和全畫面面板明暗相反(淺紙底 + 深字), 只給教學用 —— **第 9 輪的暫停式引導卡也用這一套紙底深字(= 新手教學), 專屬的是「聚光燈挖空 + 暖黃描邊 + 暖黃粗箭頭」**。

## 4. 理念落實

- P0 辨識度先於好看: 爆竹刺蝟用「半圓背 + 一排紅爆竹棒」剪影, 和齒輪甲蟲(整圈齒輪)分開;石碑用三種刻紋(心 / 繩圈 / 劍)+ 三色區分種類, 不靠字;樓梯和出口方向相反(洞 + 下箭頭 vs 拱門 + 上箭頭);**鑰匙寶箱整箱金 + 雪花 + 外圈光環, 一眼和木箱分開**。**(第 12 輪)同一層的三種「換地方」格靠剪影分: 往下樓梯 = 方框裡的暗洞、往上樓梯 = 凸起的台階量體(有立面、有落地影子)、出口 = 圓拱門框 + 發亮的門洞;往上樓梯和出口雖然都是朝上箭頭, 只有出口有門框與亮光**。
- P1 視覺權重跟著決策迫切度走: 地下城裡最亮的仍是前搖「!」與預警圈;石碑、寶箱的金光只是小光點(週期 1.5 秒脈動)不搶危險;熱度表上最粗、最深描邊的是失控線;**暫停式引導中全畫面壓暗, 唯一亮著的是聚光燈框住的那一小塊 + 指向它的暖黃箭頭**(遊戲暫停, 沒有即時決策, 引導卡可以蓋過一切)。
- P2 規則上存在的東西畫面上就要存在: 瞄準記號直接畫出「現在按空白鍵會瞄到誰、會不會套上」;節目單把「暗號不夠(鎖頭 +「待解鎖」)」「先排上面(往上箭頭)」「先選暗號(表演卡格變暗)」三種不能排畫成三個樣子;**選擇面板把「選了會互換(亮 + 青色⇄膠囊)」「選了不行(灰 +「第 N 列」)」畫成兩個樣子**;**引導卡「還不能按 Z」= 鍵帽半透明 + 進度環正在填, 滿 3 秒才亮**;**目前列等很久(≥ 10 秒)= 橘框脈動**(暗號卡住看得出來)。**(第 11 輪)進場過場的隊伍 = 這趟真的收服的每一隻, 抓幾隻畫幾隻、不截斷不收合(收服數是規則上的結果, 畫面上不能少)**。
